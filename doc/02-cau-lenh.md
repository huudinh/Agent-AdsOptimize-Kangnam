# 02 · CÂU LỆNH — ADS OPTIMIZE (KANGNAM)

---

# 1. Công thức ra lệnh

```
MODE [1|2|3|4] — [từ khóa / cụm từ khóa / số liệu / tên ZONE + ngân sách].
[dịch vụ] · [giai đoạn phễu nếu biết] · [cơ sở nếu chạy local]
```

**Bắt buộc:** mode (hoặc để Agent tự suy) + input tương ứng.
Thiếu giai đoạn phễu → Agent tự map và **nói rõ đã map vào đâu, vì sao**.

# 2. MODE 1 — WIN-AD

## 2.1 Một nhóm từ khóa
```
MODE 1 — từ khóa "nâng mũi cấu trúc giá bao nhiêu hà nội".
Chấm cổng WIN trước; qua cổng thì sinh mẫu Google RSA + Meta.
```

## 2.2 Lô từ khóa, lọc trước
```
MODE 1 — chấm cổng WIN cho danh sách này, chỉ báo cái nào qua/không qua
và vì sao. Chưa viết mẫu:
- hút mỡ bụng giá bao nhiêu
- thẩm mỹ viện uy tín
- gọt hàm v-line có nguy hiểm không
- cắt mí mắt là gì
- nâng ngực nội soi ở đâu tốt tphcm
```

Duyệt xong:
```
Ok, viết mẫu cho 2 từ khóa đã qua cổng.
```

## 2.3 Chỉ cần hook
```
MODE 1 — chỉ cần hook. Cho mình 6 hook khác archetype cho
"khắc phục mũi hỏng", giai đoạn 3. Ghi rõ archetype và bằng chứng dùng.
```

## 2.4 Chạy local theo cơ sở
```
MODE 1 — từ khóa "trị nám ở đâu tốt đà nẵng", chạy cho Kangnam Đà Nẵng.
Kiểm tra phạm vi giấy phép và TUYẾN của cơ sở này trước khi viết.
```

## 2.5 Từ khóa đại phẫu + tỉnh (bẫy tuyến)
```
MODE 1 — từ khóa "nâng ngực đà nẵng". Đà Nẵng là viện tỉnh nên không làm
đại phẫu. Cho mình 2 phương án xử lý và khuyến nghị chọn cái nào, trước khi
viết bất cứ mẫu nào.
```

## 2.6 Bổ sung biến thể cho lô đang chạy
```
MODE 1 — lô T1 đang chạy 3 hook, cần thêm 2 challenger mới cho vòng sau.
Giữ nguyên body và offer, chỉ đổi hook.
```

# 3. MODE 2 — LDP-BUILD

## 3.1 Dựng landing từ cụm từ khóa
```
MODE 2 — cụm từ khóa quanh "hút mỡ bụng Lipo 360", giai đoạn 3, chạy Google Ads.
Chốt khung theo nguồn traffic rồi dựng blueprint 13 section + copy.
```

## 3.2 Khung A2 — trả lời trước
```
MODE 2 — landing khung A2 cho "hút mỡ có nguy hiểm không".
Hero gọi đúng nỗi lo rồi TRẢ LỜI NGAY ở section 2, không khoét sâu.
Phần gỡ 3 rào cản viết kỹ, đây là phần quan trọng nhất.
```

## 3.3 Dựng thẳng HTML
```
MODE 2 — dựng thẳng HTML single-file cho landing nâng ngực nội soi, giai đoạn 4.
Mobile-first 360–430px, container .app 480px, Design System Kangnam v3.0,
khung trang theo kn-khung-landing.md. Micro-conversion trước form.
Ảnh chưa có thì dựng ô ảnh tạm + bảng kê ảnh cần cấp.
Kiểm tuyến trước khi gắn địa chỉ footer.
```

## 3.4 Landing cho khách tỉnh
```
MODE 2 — landing cho khách Đà Nẵng quan tâm nâng ngực.
Nói rõ ngay ở hero: khám và tư vấn tại viện tỉnh, PHẪU THUẬT TẠI TUYẾN
BỆNH VIỆN. Tuyệt đối không mời mổ tại Đà Nẵng.
```

## 3.5 Sửa landing đang có
```
MODE 2 — landing hiện tại CTR tốt nhưng không ai điền form.
Đề xuất sửa phần nào, theo thứ tự ưu tiên. Chưa viết lại cả trang.
Kiểm luôn: khung có đúng theo nguồn traffic không, micro-conversion có
đứng trước form không.
```

## 3.6 Rà soát trước khi đẩy traffic
```
MODE 2 — rà soát landing [đường dẫn] theo 12 câu trong
prompts/prompt-build-landing-page.md §4. Kết luận ĐƯỢC CHẠY / SỬA RỒI CHẠY
/ LÀM LẠI.
```

# 4. MODE 3 — LDP-ADVISOR

## 4.1 Chẩn đoán đầy đủ
```
MODE 3 — số liệu 14 ngày, nhóm "nâng mũi cấu trúc HN":
ADS: impression 42.000 · CTR 2,1% · CPC 18.000đ · CPL 890.000đ · chi phí 32tr
GA: scroll depth 35% · time-on-page 28s · form view 310 · submit 22 · booking 6
Chẩn đoán và cho mình 3 quyết định.
```

## 4.2 So sánh với control
```
MODE 3 — mẫu A: CTR 2,8% CPL 740k · mẫu B (control): CTR 2,1% CPL 890k.
Impression A 9.000, B 41.000. A có phải winner không, scale được chưa?
```

## 4.3 Đọc tới ca chốt, không chỉ CPL
```
MODE 3 — nhóm X: CPL 600k, booking rate 18%, show-up 55%, chốt 30%.
Nhóm Y: CPL 1,1tr, booking rate 42%, show-up 70%, chốt 45%.
Nhóm nào nên dồn ngân sách? Tính theo chi phí/ca chốt.
```

## 4.4 Thiếu dữ liệu
```
MODE 3 — mình chỉ có CTR và CPC, chưa gắn GA.
Với dữ liệu này kết luận được gì, chưa kết luận được gì?
```

# 9. Những gì Agent sẽ TỪ CHỐI hoặc CẢNH BÁO

| Yêu cầu | Phản hồi của Agent |
|---|---|
| "Viết Kangnam số 1 / tốt nhất Việt Nam" | Từ chối; nêu từ cấm; đề xuất USP đo được (287/BYT-GPHĐ · KCCS · bảo hành) |
| "Ghi cam kết không biến chứng / đẹp tuyệt đối / an toàn tuyệt đối" | Từ chối; đề xuất ngôn ngữ xác suất + bằng chứng + dấu `*` |
| **"Ghi 3 ngày là đi làm bình thường"** | Từ chối hứa thời gian hồi phục cứng; đổi sang dạng khoảng + *"tùy cơ địa"* |
| **"Ghi không để lại sẹo"** | Từ chối; nói về vị trí đường mổ và cách hạn chế sẹo |
| "Điền đại giá vào cho có" | Từ chối; `[CHỜ CẬP NHẬT]`; nhắc giá là dữ liệu động lấy tại `/bang-gia/` |
| "Lấy giá lần trước bạn viết ấy" | Từ chối; số cũ có thể đã sai — bắt buộc lấy mới |
| "Bịa số ca cho hook mạnh hơn" | Từ chối; đổi sang archetype khác không cần số |
| "Thêm tên bác sĩ X cho uy tín" | Kiểm tra danh sách bác sĩ; không có → `[CHỜ CẬP NHẬT]` |
| "Viết review khách cho sinh động" | Từ chối bịa review; hỏi có review thật đã duyệt chưa |
| "Dùng ảnh before-after này" | Hỏi đã duyệt pháp lý + có giấy đồng ý chưa; chưa có → không dùng |
| "Tạo ảnh mô phỏng kết quả" | Từ chối; không tạo ảnh kết quả giả |
| **"Chưa có ảnh thì lấy ảnh stock/AI cho đủ"** | Từ chối; dựng **ô ảnh tạm** viền đứt + bảng kê ảnh cần cấp |
| "So sánh trực diện với [tên đối thủ]" | Từ chối nêu tên hạ thấp; đề xuất bộ tiêu chí khách quan |
| "Từ khóa này mình thích, cứ viết đi" (chưa qua cổng) | Cảnh báo < 2/3 tiêu chí, nêu rõ thiếu tiêu chí nào; đề nghị thu hẹp từ khóa |
| "Xuất luôn, khỏi chấm điểm" | Cảnh báo chưa chấm WIN 12 điểm; mẫu < 10/12 không nên chạy |
| "Scale mẫu này đi" (mẫu nhỏ) | Cảnh báo chưa đủ hiển thị/chi tiêu để kết luận winner |
| **"CPL rẻ nhất thì dồn ngân sách vào"** | Hỏi lại booking rate và chi phí/ca chốt; lead rẻ chưa chắc lead tốt |
| **"Landing chạy Ads dùng PAS cho nó sâu"** | Sửa lại: landing chạy Ads **luôn là AIDA** (A1/A2); PAS chỉ cho SEO/GEO/social nguội. Nêu cả lý do **rủi ro tuân thủ** |
| **"Khoét sâu nỗi sợ cho khách thấy nguy hiểm"** | Từ chối; QC dịch vụ KCB **không được gây hoang mang** |
| **"Quảng cáo nâng ngực cho viện tỉnh"** | Cảnh báo đại phẫu chỉ tuyến bệnh viện; đưa ra **2 cách xử lý** rồi chờ chọn |
| **"Gắn địa chỉ viện tỉnh vào landing mời đại phẫu"** | Từ chối; vượt phạm vi giấy phép |
| **"Xin số điện thoại ngay ở hero"** (ca đại phẫu) | Cảnh báo; đề xuất micro-conversion trước form |
| **"MODE 4: điền luôn volume và CPC ước lượng"** | Từ chối ước lượng; để trống 2 cột cho Keyword Planner |
| **"MODE 4: chia ngân sách theo volume"** | Sửa lại: chia theo **ý định mua × giá trị ca** |
| **"MODE 4: gộp ZONE Mũi và Mắt cho đỡ việc"** | Từ chối; rào cản khác nhau thì bằng chứng gỡ cũng khác nhau |

| "Gửi ảnh hồ sơ bệnh án khách để viết case" | Từ chối; không nạp dữ liệu bệnh nhân lên công cụ công cộng |
